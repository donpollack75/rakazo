# P02 — Notes on your own build

HARD RULE: English only.

Study the general idea that a compiler you run can leave named sections in a binary built from source you own. Using only a binary built from an owned project the operator names, write short notes in your own words describing what you asked the compiler to produce.

Then add one original command that prints the output file name and size for that build. Keep the command inside the owned project.

Rules for this prompt:

- Do not open or inspect Microsoft Word, Excel, PowerPoint, or Paint.
- Do not reverse engineer an operating system or any binary you do not own.
- Do not write an exploit proof of concept.
- Do not design or build an Office-suite clone.
- Do not turn the notes into a copy of another product's behavior.

If the operator has not named an owned project and its build output, ask for that path and wait.
