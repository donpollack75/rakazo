# P03 — Original utility from a written spec

HARD RULE: English only.

Pick a small original utility that is not an office application. A log-line counter or a config-key checker is the right size. Write a short spec in your own words, then implement that spec in an owned project the operator names.

The spec states the inputs, the output, and one error case. Behavior comes from that spec.

Rules for this prompt:

- Do not open or inspect Microsoft Word, Excel, PowerPoint, or Paint.
- Do not reverse engineer an operating system or any product you do not own.
- Do not write an exploit proof of concept.
- Do not design or build an Office-suite clone, and do not derive features by reversing one.
- If the request is to copy an existing office application, refuse and stop.

If the operator has not named the owned project directory, ask for it and wait.
