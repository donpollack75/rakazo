# P01 — Own-build file facts

HARD RULE: English only.

Study the general idea of identifying a file you produced yourself: its name, its size, and a hash. Then build a small original command-line tool that prints those three facts for one path.

Rules for this prompt:

- The path must be a file the operator owns and names, inside an owned project.
- Refuse paths outside that project.
- Do not open or inspect Microsoft Word, Excel, PowerPoint, or Paint.
- Do not reverse engineer an operating system.
- Do not write an exploit proof of concept.
- Do not design or build an Office-suite clone.

The tool's behavior comes from this written spec, not from another product's binary.
